# Audio asset note

The only source of PixelLegends product, visual, gameplay, and technical requirements is [`docs/PROJECT_SPEC.txt`](../../../docs/PROJECT_SPEC.txt). The current UI-shell milestone does not approve match music or gameplay-audio features.

Add audio only as part of an explicitly approved phase. Use original or properly licensed material, keep attribution in `THIRD_PARTY_NOTICES.md` where required, and update the live status in the project specification after verification.
